# Task 1 - Part H: RISC-V Assembly Language Programming & C Implementation

## 📌 Overview
This repository section contains the implementation and documentation for **Task 1 - Part H** of the **Sumerix Global VLSI Internship**. The task focuses on understanding RISC-V ISA (Instruction Set Architecture), writing assembly/C programs, simulating them using EDA tools, and analyzing the resulting waveforms and register states.

---

## 🎯 Objectives
- Write and compile RISC-V C and Assembly programs.
- Understand RISC-V register usage, function calling conventions, and instruction encodings.
- Perform simulation using RISC-V toolchains and open-source EDA tools (e.g., Spike / Icarus Verilog / GTKWave).
- Analyze waveform outputs and verify register values post-execution.
