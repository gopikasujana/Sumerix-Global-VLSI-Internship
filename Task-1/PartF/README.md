
# Part F – 4-bit Ripple Carry Adder

## Objective

Design and verify a 4-bit Ripple Carry Adder using Full Adder modules.

## Design

Four Full Adders are connected in cascade so that the carry output of one stage becomes the carry input of the next stage.

## Files

- RTL source
- Testbench
- Waveform

## Verification

The design was simulated using Icarus Verilog and the resulting waveform was analyzed using GTKWave.
